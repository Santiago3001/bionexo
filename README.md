# BioNexo NEA

**Plataforma inteligente de conexión productiva, comercial, logística y ambiental**

> Conectamos lo que producís con quien lo necesita.

## Identidad del proyecto

- **Proyecto:** Ideathon NEA Tech 2026.
- **Vertical:** NEA Productivo Digital.
- **Escenario:** Del subproducto al mercado.
- **Caso de demostración:** aprovechamiento comercial de cascarilla de arroz en el Nordeste Argentino.
- **Equipo:** PENDIENTE.

## Problema

Las arroceras del NEA necesitan encontrar compradores compatibles para su cascarilla de arroz porque la búsqueda comercial es dispersa y puede dejar material acumulado, desaprovechado o con una salida de bajo valor.

La existencia y la magnitud económica de este problema todavía deben validarse con actores reales. Las afirmaciones sobre acumulación, costos y dificultad para conseguir compradores están marcadas como **SUPUESTO**.

## Resumen del producto en cuatro líneas

1. **Problema:** una arrocera puede generar cascarilla sin conocer compradores cercanos, aplicaciones posibles ni el costo total de concretar una operación. **SUPUESTO**.
2. **Solución:** BioNexo interpreta una oferta y recomienda compradores compatibles usando cantidad, ubicación, frecuencia y requisitos técnicos.
3. **Negocio:** la hipótesis inicial combina acceso gratuito con comisión por operación y servicios empresariales pagos. **SUPUESTO**.
4. **Blockchain:** no se necesita para el prototipo; la prioridad es validar la conexión comercial con una base de datos y una consulta real a una API de IA.

## Prototipo propuesto

La demostración se concentra en una sola acción: una arrocera informa que dispone de cascarilla y BioNexo devuelve una recomendación comercial explicada.

El prototipo utilizará entre 8 y 12 perfiles y operaciones identificados como **DATO SIMULADO**. La IA deberá interpretar al menos una consulta real, consultar los datos disponibles y completar una acción demostrable sin inventar proveedores, precios ni requisitos técnicos.

## Estado de validación

El documento de origen presenta una visión de producto, pero no incluye entrevistas, estudios de campo, cotizaciones ni operaciones reales. Por eso:

- Los perfiles, cantidades, precios y coincidencias usados en la demo serán **DATO SIMULADO**.
- Los dolores, costos, disposición a pagar y tamaño de mercado se consideran **SUPUESTO** hasta validarlos.
- Las recomendaciones de usos de la cascarilla deberán revisarse con especialistas antes de mostrarse como técnicamente viables.
- Los reportes ambientales serán informativos y no certificaciones oficiales.

## Contexto para IA

BioNexo NEA es una propuesta para conectar actores productivos del Nordeste Argentino. Su visión futura reúne descubrimiento comercial mediante inteligencia artificial, logística, mensajería, contratos recurrentes y medición ambiental. Para la Ideathon, el alcance se reduce al escenario “Del subproducto al mercado” y al caso de la cascarilla de arroz.

El usuario principal del prototipo es una arrocera que publica material disponible. BioNexo interpreta el texto, extrae producto, cantidad, ubicación y frecuencia, consulta una base con compradores simulados y devuelve coincidencias explicadas. Los cálculos de distancia, costo y compatibilidad deben provenir de módulos controlados; la IA solo interpreta y presenta resultados.

La hipótesis principal es que descubrir una contraparte comercial compatible es un problema relevante. Esta hipótesis no está validada. Antes de ampliar el producto se deben entrevistar arroceras, cooperativas, potenciales compradores y transportistas; medir el proceso actual; y comprobar si existe disposición a pagar. El prototipo no necesita blockchain, pagos, certificaciones ni un sistema contractual completo.
